GPU Performance · MoE

H200 MoE / Grouped GEMM：先把统计语义对齐，再谈 Kernel 调优。

面对 MoE 热路径，最危险的不是“没有 Profile”，而是拿着错误的 rows、shape 或 expert 分布做 Profile。这个项目围绕线上 NVTX range、DeepEP compact rows、本地 replay 与 SM90 config tuning，建立从观测到决策的性能闭环。

RoleProfiling & Kernel Tuning
HardwareNVIDIA H200 · SM90
StackNsight · CUTLASS · Quack
ScopeGrouped GEMM · MoE Hot Path
01 / Problem

同一个“rows”，在不同模块里可能根本不是同一个工作量。

MoE 中一个 token 会被 router 分配给 top-k experts。上游常用 T × topk 表示全展开 rows，但通信/dispatch 后可能经过 response mask、capacity、drop 或 compact，真正进入 Grouped GEMM 的是 TK_valid。如果用前者解释后者的 Kernel latency，就会严重低估或高估吞吐。

关键发现

将全展开 rows 与 DeepEP compact rows 混用，会造成约 4×–6× 的性能口径误判。优化前先修正“测的到底是什么”。

02 / Pipeline

MoE 热路径中的 shape 形成过程

RouterT × topk assignments
Mask / Compactvalid token rows
Dispatchexpert distribution
Grouped GEMMgemm_gated / gemm_out
Combinerestore token order

单看矩阵 M/N/K 仍然不够。Grouped GEMM 的性能还取决于每个 expert 的 rows 分布、group 数、空 expert、长尾负载、数据类型、epilogue、调度策略与运行时开销。

03 / Method

从线上 Profile 到本地可控 Replay

  1. 统一口径：确认每个 range 中的 rows 是全展开、mask 后有效值，还是 dispatch 后 compact rows。
  2. 采集代表样本：从线上执行中抽取 1024 条 forward range，保留 shape、expert 分布与调用类型。
  3. 构造本地回放：在相同 GPU 与软件栈上复现代表性 shape，避免训练框架其他阶段干扰。
  4. 对齐误差：比较线上与本地 profile 的 latency / MFU，确认 replay 是否足以支撑配置选择。
  5. Config tuning：围绕 SM90 候选 tile、cluster、pipeline 等参数增加 autotune 搜索空间。
04 / Replay Validation

本地回放必须先证明“像线上”。

这些差异说明 replay 可以作为调优筛选工具，但不能把每个微秒差异都解释为线上收益。对于误差较大的 shape，需要继续检查 expert rows 分布、warm-up、频率、其他流并发和内存状态。

05 / Tuning

SM90 Config-level Tuning

参与 Quack / CUTLASS Grouped GEMM 的候选配置扩展，围绕 gemm_gated 与 gemm_out 比较 latency、MFU 和不同 expert 分布下的稳定性。补充候选并不是越多越好，而是要让搜索空间覆盖目标 shape 的计算/访存特征。

单个 shape 的最佳配置不一定适用于不同 rows 分布。最终应在多个 shape × 多种 expert 分布上比较，并评估 autotune 时间、二进制体积和运行时选择开销。

06 / Performance Reasoning

我如何判断一个 Grouped GEMM 为什么慢

工作量是否真实

rows、top-k、mask、compact、group count 与 expert 分布是否一致。

Kernel 是否吃满

Tensor Core 利用率、occupancy、tile 浪费、长尾 group 与 launch overhead。

数据移动是否主导

dispatch/combine、TMA、L2 命中、写回、epilogue 与中间 buffer。

系统是否干扰

其他 stream、通信 overlap、频率、warm-up、CUDA Graph 与 range 边界。
